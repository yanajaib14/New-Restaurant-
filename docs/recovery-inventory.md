## Staged priorities from source evidence

1. **Shared-data correctness:** remove successful-empty cache overrides for tasks, notes and checklists (`App.tsx:478–490`) and todos (`512–527`); do not report the unavailable durable queue as implemented.
2. **Complete inventory and operations:** render the missing MasterInventory table and wire `onView` (`MasterInventory.tsx:101`, `App.tsx:4113`); consolidate duplicate Inventory routes and tie shopping/menu/vendor references to stable inventory IDs.
3. **Truthful launch scope:** remove invoice feature, avoid invented seed data, and implement requested Permits & Accounts structure and expiry reminders.
4. **Identity and privacy:** establish real individual identity and server enforcement before claiming partner-specific access, notifications, or confidentiality; the PIN is local only (`App.tsx:407`).
5. **Forms and workflow:** review every async save path in a running mocked environment, including AI prompt handling and calendar draft behavior; unify task/review workflow only after shared writes are reliable.
6. **Visual and mobile verification:** inspect every listed control in browser at desktop/mobile sizes only after source fixes; this report contains no visual or runtime verification.
